# 强制事实卡规范

系统先抽取事实卡，再判断两份材料是否冲突。没有通过字段校验的事实不会进入比较，避免仅凭一句相似文本直接下结论。

## 通用必备字段

| 字段 | 含义 | 示例 |
| --- | --- | --- |
| `subject` | 事实作用的对象 | 陈皮、脾、五色健脾粥 |
| `attribute` | 被描述的属性 | 食材剂量、后下时长、脏腑属性 |
| `relation` | 断言关系 | 建议用量、时间要求、后放、先天之本 |
| `value` | 数值或原文值 | 8 克、5～10 分钟、后天之本 |
| `unit` | 单位，非数值事实可为空 | 克、分钟 |
| `timeType` | 时间语义类型 | 总烹饪时长、后下时长、课程周期 |
| `population` | 适用人群，没写时记为“未限定” | 糖尿病、控糖 |
| `condition` | 执行条件，没写时记为“未说明” | 饭后、出现症状时 |
| `sequence` | 操作顺序，没写时记为“未说明” | 先下、后下、同煮 |
| `polarity` | 肯定、否定或中性 | 推荐/避免 |
| `evidence` | 生成该事实的原文片段 | 广陈皮8克 |
| `source` | 文件、位置、语义段和原文 | PDF 第 17 页 |

## 分类字段要求

| 类别 | 额外强制要求 |
| --- | --- |
| `dose` | 必须有可比较的数值范围和单位 |
| `time` | 必须识别 `timeType`，不能只存“30分钟” |
| `concept` | 必须有明确对象和关系，例如“脾/后天之本” |
| `order` | 必须存执行顺序，例如“同煮/后下” |
| `scope` | 必须存人群和肯定/否定倾向 |
| `property` | 必须存四气、五味或归经及其具体值 |
| `structure` | 必须存操作名称或结构数量 |
| `direction` | 必须存穴位或操作对象、方向；缺少方向时标记为字段缺失 |

## 冲突判定原则

- 剂量：相同食材、相同人群和相同单位族之间比较；范围无交集为高危。
- 时间：只有相同 `timeType + subject + population` 才比较，禁止把课程周期和烹饪时长混在一起。
- 概念：同一对象的属性互斥时才判定冲突。
- 顺序：同一配方既写“全部食材同煮”又写“某食材后下”时判定冲突。
- 性味归经：同一食材的四气、五味、归经不一致时分别判定；归经和五味的书写顺序不计为差异。
- 结构：同课材料的操作名相近但不同列为低危；结构数量不一致列为低危。
- 周期：6天体验营和5天训练营属于同一种课程周期，可直接对比。
- 穴位方向：同穴方向不同列为高危；一份材料有方向、另一份只提穴位名称时列为中危缺项。
- 作业：答案或解析中的知识点与视频正文冲突时列为高危，并关联课程原文。
- 单份材料内部重复出现的事实也参与检查，不只比较两份文件。
